Scope

Final behavior
- Saved positioning, audience need, promise, distinctive principle, typography and
  color roles reach fresh brand image requests independently of direction prose.
- Strategy is advisory, and the full persisted Strategy remains unchanged.
- Image context omits assumptions; fields are capped at 320 characters with a
  visible ellipsis and reduced further to fit the remaining 20,000-character
  allowance. If that allowance is already full, optional context is omitted without
  truncating original brief/direction data.
- Explicit user text/color/canvas data remain separate; advisory color intent is
  not described as proof of exact raster palette compliance.
- App-icon/IP requests do not acquire the brand-only strategy projection.
- Edit parent instructions are historical; latest scoped feedback is current.
- New generation-only guidance and strategy occupy a separately framed optional
  suffix. The mandatory request is smaller than the previous builder for the same
  input. An edit omits only a suffix with the recognized generated-brand framing;
  user brief/direction/parent identity and current keep/change are retained. Legacy
  marker-like user text is preserved. The saved parent prompt itself is unchanged.
- Repeating public start emits no duplicate images. Immutable helper brief bytes,
  agreed image counts and planning/critique budgets remain unchanged.
