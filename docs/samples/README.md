## Try a lettering brief

> $logo-land Create a playful multicolor wordmark for LUMA using the exact text LUMA. Build the personality into chunky letter shapes and their spacing. Do not add a separate icon, tagline or extra text.

> $logo-land 고요의 한글 워드마크를 만들어 주세요. 정확한 글자는 고요이며, 둥근 획과 넉넉한 글자 간격으로 차분한 분위기를 표현해 주세요. 별도 심볼이나 추가 문구는 넣지 말아 주세요.
