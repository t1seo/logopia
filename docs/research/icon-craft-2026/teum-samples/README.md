# ‘틈’ — 개선 후 추가 샘플 3개

사용자의 추가 샘플 요청으로 새로 생성했습니다. 바쁜 업무 중 짧은 산책과 휴식을 돕는 가상의 앱이며, 목표·연속 기록 압박 없이 잠깐 밖으로 나오는 인상을 의도했습니다.

각 `*-spec.json`은 설계 의도이며 위 표는 실제 PNG 관찰입니다. 현재 개선된 Helper로 최종 프롬프트를 만들었습니다. 열린 통로 후보는 직접 확인한 Gentler Streak Reference의 비대칭·실루엣 원칙을 **텍스트 분석으로만** 전달했습니다. 원본 제품 이미지나 고유한 주황색 하트 윤곽을 이미지 입력으로 전달하지 않았습니다. 나머지 두 후보는 Reference 이미지 입력이 없습니다.

세 번 모두 `image_gen__imagegen`에서 실제 반환된 **1254×1254 PNG**입니다. 모델·seed는 unreported이며, 원본을 보정하거나 실패한 후보를 버리고 재추첨하지 않았습니다. 기본 SEAM 비교 6회와 합쳐 생성 **9회/한도 12회**, 수정 0회입니다. [전체 예산](../call-budget.json)

원본 Session은 `teum-craft-open-passage`, `teum-craft-hangul`, `teum-craft-ceramic-bench`, 후보 ID는 각각 `v1`입니다. Gallery의 `teum-craft-samples`는 같은 원본 바이트와 Prompt를 가져온 별도 카탈로그이며 추가 생성이 아닙니다. 사용자 선택·승인·선호 결과는 기록하지 않았습니다. 이 세 후보는 두 번째 Brief의 추가 샘플이며, 새 Baseline을 포함한 통제 A/B 실험은 아닙니다.
