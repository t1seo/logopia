# Logopia 문서

[English](README.md) · [한국어](README.ko.md) · [Logopia](../README.ko.md)

브랜드가 전할 의미를 정하고, 어울리는 형태를 고른 뒤, 글자와 작은 크기에서의 식별성을 다듬어 보세요. Codex 스킬이나 단계별 Hermes 워크플로로 개성 있는 레터링, 브랜드 로고와 앱 아이콘 아트워크를 만드실 수 있습니다.

## 샘플

- [10월 1일 실험 — 디자인 품질 거절](showcase/2026-10-01-use-cases/README.md): 사용자가 여섯 결과 모두 의미 있는 개선과 실사용 품질에 미치지 못한다고 거절했습니다. 원본 PNG·요청·수정 이력은 보존했습니다. 품질 개선은 입증되지 않았으며, 브라우저 QA는 사용성만 확인했습니다. [오프라인 HTML](showcase/2026-10-01-use-cases/index.html).
- [10월 1일 브랜드 품질 비교](qa/brand-output-quality-2026-10-01/README.md): 미발행 0.9.0 워크플로의 변경 전후 원본 6장, 실제 프롬프트·측정값과 남은 한계를 보존했습니다.
- [9월 20일 보관 샘플 24개](showcase/2026-09-20-lifestyle/README.ko.md): 문구·차·책·반려동물과 생활 앱의 당시 원본·프롬프트·작은 크기 진단입니다.
- [9월 19일 앱 아이콘 조형 비교](research/icon-craft-2026/README.md): 원본 6개와 변경 전 프롬프트를 보존한 과거 실험입니다. 이후 사용자가 Candidate 2·5의 형태와 색상을 거절했으므로 선호 개선의 증거로 취급하지 않습니다.
- [과거 OFFCUT Hermes 사례](hermes-demo/README.ko.md): 최초 원본 3개, 정확한 부모 원본을 기준으로 한 수정 2개와 전달된 e2 ZIP입니다. 첫 수정본의 보존 검사 실패도 그대로 표시합니다. 폴더를 내려받아 HTML 페이지를 로컬에서 열면 오프라인으로 비교하실 수 있습니다.
- [2026년 9월 갤러리](gallery.ko.md#september-20-2026): 당시 흰 배경 브랜드 로고 10개, 앱 아이콘 12개(색 배경 6개·흰 배경 6개), OFFCUT 방향 2개입니다. 원본 24개를 바로 여실 수 있습니다.
- [브랜드 샘플 보관 자료](samples/README.ko.md): 9월에 생성한 LUMA, LOOP LAB, 고요, BREAD & BLOOM, KITE, MISO, NORTHLINE / NL, 물결, FERN, NOVA NOTES와 이전 예제 링크입니다.
- [Logopia 로고](brand/README.ko.md): 흰색 배경 위 다채로운 소문자 게임 타이틀 레터링과 이전 디자인입니다.
- [이전 앱 아이콘 예제](app-icons/README.ko.md): 앞선 컬렉션의 IP 시안 6개와 원본·수정 방향 비교 5쌍입니다.
- [이전 색상·타이포그래피 사례](colors/README.ko.md): 프로젝트 7개의 사례 8개와 당시 기록된 결과입니다.
- [투명 PNG 예제](samples/transparency.ko.md): 이전에 만든 GROVE 예제와 배경 사용 안내입니다.

[README의 거절된 실험](../README.ko.md#샘플)은 기본적으로 접혀 있으며 원본 PNG 링크를 보존했습니다. [이전 컬러 쇼케이스](showcase/2026-09/README.ko.md)는 역사 자료이며, 검증된 품질 기준으로 격상하지 않았습니다.
