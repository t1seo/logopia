# Pebble — focused comparison after rejected samples

This is an experiment, not an approved identity or a production-quality showcase.
The user rejected all six October examples: their design quality did not show a
meaningful improvement. The [original Pebble](../2026-10-01-use-cases/images/05-pebble.png)
remains unchanged as the baseline. [Open the comparison](index.html).

## What went wrong

The new helper records briefs, requests, parents and critique decisions. Those
engineering changes did not establish better taste or craft. The sample run then
bypassed that loop: six separate first generations and two background corrections
were presented as examples of the update. File integrity and working gallery
controls were verified, but they did not answer whether the logos were good.

The mode instructions also allowed a fixed candidate count to select fast mode
while a quality-improvement objective was still active. The skill now gives that
objective precedence across subsequent sample and README requests. For collections,
it preserves separate brand records and one explicitly bounded total call budget.

## Reference decisions

The sources inform the design hypotheses; their appearance is not copied.

- [Pentagram — The High Line](https://www.pentagram.com/work/the-high-line): the
  identity accompanies a real elevated park and its wayfinding system. Our visual
  observation of the official signage is that the compact H/rail-like structure
  works as an identifier, rather than a picture of a pleasant landscape.
- [Otherway — Loaf](https://www.otherway.com/work/loaf): the studio describes
  refining an existing handcrafted logo for digital clarity while giving a
  simplified blue palette a clear role. Our inference is that comfort need not
  make every element equally round or soft.
- [COLLINS — Ogilvy](https://wearecollins.com/case-studies/ogilvy/): the documented
  transition from a personal signature to redrawn Baskerville connects a specific
  typographic decision with the organization's identity. Adding “premium” to a
  prompt is not an equivalent design decision.

These are professional reference cases, not a benchmark proving that Logopia
matches their quality. The fictional Pebble brief is a personal journal of
unhurried urban walks, not an exercise tracker. We are testing whether lettering
can give it a clearer identity than the generic stone-and-path combination.

## Actual experiment

The [brief](brief.json) and [contract](contract.json) freeze the name, plum-on-white
master, two distinct lettering hypotheses and a maximum of **three native calls**.
The earlier icon is not an edit parent: this study explores a new wordmark.
Actual tool requests, unchanged PNGs and reviews are retained alongside this file.
The native tool does not expose its model identity, seed or vector paths.

Comparison views use the original PNGs and CSS-only sizing/cropping of exterior
margins. They do not redraw, recolor or replace the artwork. A visible 240px logo
and a 360px mobile journal context are the specified checks. No favicon, print,
transparent master or editable font output is implied.

The original-size independent review of the first new result found a clearer
focus on the name but a familiar retro soft-serif construction and heavy `b-b-l`
rhythm. It did **not** establish meaningful overall design improvement. The review
is separate from the director who proposed the construction.

## Final outcome: stopped without a suitable candidate

Two native generations were used. The third allocated call was left unused because
the independent critic did not identify a useful next refinement. No selection,
approval or export was recorded. See the [manifest](manifest.json), exact
[loop record](loop-record.json) and [reviews](reviews/02.json).

| View | Actual result | Decision |
| --- | --- | --- |
| X — earlier result | Familiar stone/path icon and round lettering; user rejected the sample | Retain as baseline |
| Y — [first new original](images/01.png) | Name has more focus, but a familiar retro serif and heavy `b-b-l` rhythm remain | Reframe; [critique](reviews/01.json) |
| Z — [second new original](images/02.png) | Wider counters improve one local relationship; tall handwritten forms still lack a distinctive identifying structure and dominate the mobile header | Stop; [critique](reviews/02.json) |

Both new names remain readable in the tested white header and journal contexts.
That is not enough to establish a better identity. This study demonstrates a more
honest rejection process, **not improved production logo quality**. It is also not
a controlled test proving an image model's general limits: the model identifier
is unknown, the proposals were director choices, and no expert vector-built
counterpart was produced.

The next design problem is concrete: sketch alternative shared curve/join rules
for `p`, `b` and `e`, compare the resulting word shapes, then build and optically
adjust a chosen construction in editable artwork. That work has not been done
here. Another adjective-heavy prompt, a tidier background or a prettier gallery
does not resolve it.

The exact records retain workspace-relative evidence paths. Official browser
captures contain unrelated browser chrome and are kept locally in ignored
`output/pebble-study-20261001/qa/`; their hashes remain in the critiques. The initial
capture was JPEG despite its temporary `.png` filename, so the helper rejected it
without changing loop state. Separate PNG codec conversions were then recorded
for evidence; logo originals were untouched. This public directory is a viewing
and audit collection, not a resumable workspace bundle or a claim that HTML source
alone proves someone inspected it.
