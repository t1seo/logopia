Same size. Same place.

X·Y·Z를 같은 화면과 크기에서 비교합니다. 세 안 모두 채택된 디자인이 아닙니다. 브라우저 사용성 검사는 디자인 승인이나 품질 판정을 뜻하지 않습니다.

검토 결과: Y는 이름에 집중되지만 익숙한 복고풍 글자, Z는 내부 공간은 나아졌으나 익숙한 손글씨와 큰 세로 비례가 남았습니다. 전체 품질 개선을 입증하지 못해 2회 생성 후 중단했고 채택한 안은 없습니다. 실험·검토 기록 읽기

표시 조건

원본 PNG의 색·형태·픽셀은 수정하지 않았습니다. 각 이미지의 밝은 바깥 여백만 CSS overflow: hidden으로 숨기고, 전체 아트워크의 보이는 너비가 240 CSS px이 되도록 비례 축소합니다. X는 심볼과 글자를 포함한 전체 폭, Y와 Z는 글자 전체 폭입니다. 글자만의 높이나 너비를 같게 맞춘 비교는 아닙니다.

읽기 전용 픽셀 분석으로 R·G·B 중 하나라도 240 미만인 픽셀의 경계를 구했습니다. 좌표는 원본 왼쪽 위 기준이며 오른쪽·아래는 포함하지 않습니다. 안티앨리어싱의 매우 밝은 경계 때문에 1px 안팎의 차이는 있을 수 있습니다. 원본 전체 보기는 표에 적힌 크기의 파일을 바깥 여백까지 그대로 보여 줍니다.
