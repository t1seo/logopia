# IP character recipe

Adapted from [s1dashu/ip-as-logo-skill](https://github.com/s1dashu/ip-as-logo-skill/blob/acb834c717bcd0a487c49732d08397ba280d690b/SKILL.md),

The default is six independent character candidates. Honor the direction and
candidate counts supplied by the host, including explicit exploration counts.
When the user specifies a subject, develop treatments of that subject. Otherwise,
derive subjects from the product and audience without category-to-animal shortcuts.
Every candidate is its own original image, never a grid.

Choose one coherent silhouette and explain its construction: body-to-head ratio,
curve or edge treatment, contacts between parts, expression and clear space. Match
these decisions to the supplied personality; an angular, serious character is as
valid as a soft, playful one. Shape count, roundness, cuteness and lower-corner
placement are choices, not requirements. Preserve explicitly requested placement,
including an intentional corner crop. Name the silhouette or facial feature that
must survive the requested display size; reduce detail only when it competes with it.

Honor supplied colors and background. Otherwise choose a palette for this product,
assigning a visible role to each subject color and to the solid filled background.
Do not prescribe a fixed palette or number of color families. Keep the material and
lighting coherent with the chosen form; incidental tonal variation is not an error.

The final image prompt keeps the product, audience and intended use together with
the chosen subject, geometry, pose, placement, color roles, material and expression.
Describe the background as filling the entire square; if white is requested, say
“solid white #FFFFFF filling the entire square.” This IP portrait path has no
lettering. Request one square original, and record actual returned dimensions;
the native tool does not expose a pixel-resolution control.

This adaptation retains independent draws and deliberate color roles from the
upstream recipe while making geometry, palette and composition product-specific.
Logopia adds saved provenance, target-size pixel reviews and exact-parent revisions.
No upstream executable code or showcase image is bundled.
